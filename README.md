========================
EXECUTION DESCRIPTION
========================

To run the project do the following:

1. set the data in <your home directory>/datos_ensembl/ 

2. java -jar bioinformants.jar <bp upstream> <mRNA|CDS>

for instance:

java -jar bioinformants.jar predictor.Data 1000 mRNA

java -jar bioinformants.jar predictor.Data 100 CDS
